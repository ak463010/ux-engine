# UX Guard Command

Inspect the AppGuard runtime architecture:

1. AppGuard script: `data/app-guard.js`
2. Automatic boot timeout reload
3. Unhandled error and promise rejection panel
4. Real-time offline banner and mutation protection
5. Form double-submit locking

To include in your project:
```html
<script src="scripts/app-guard.js"></script>
```
